# رحلتي — Travel Planner

Arabic mobile-friendly trip planner: trips, daily itinerary, places with photos and map links, expenses in JOD, and notes. Data is stored locally in the browser. Export a trip as JSON to back it up and import it on another device.

## Publish with GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Site: https://mothana992.github.io/my-trave1-planner/

On Android Chrome, open the site and select **Add to Home screen** to install it. Export backups regularly: clearing browser data can remove saved trips and images.

Use the **English / العربية** button in the header to switch interface language. Your trip content stays as entered.
